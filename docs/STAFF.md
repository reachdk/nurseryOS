# NurseryOS for staff

## App URL

**https://nursery-os.vercel.app**

Bookmark on your phone and desktop.

## Sign in

1. Open the link above.
2. Enter the **email and password** your admin created in Supabase (not your personal Supabase account).
3. Tap **Sign in**.

If login fails on the website but worked on the admin’s laptop, ask admin to complete [Supabase Auth URL setup](VERCEL_DEPLOY.md#4-supabase-auth-urls-required-for-production-login).

## Daily use

| When | Where |
|------|--------|
| Sales, parties, invoices | **Vyapaar** (all day) |
| Plant batches, move to office, loss | **NurseryOS** |
| End of day stock update | **NurseryOS → Sync** (Vyapaar sales export) |

## Need an account?

Ask the nursery admin to add you: Supabase dashboard → Authentication → Users → Add user.
